# Overview

Alcohol rehabilitation programs often face challenges in identifying whether patients are genuinely progressing toward recovery or silently developing relapse tendencies.

The **Hidden Intent Tracing Tool (HITT)** is an AI-based handwriting analysis system designed to assist clinicians and researchers in detecting behavioral indicators related to relapse or recovery among individuals undergoing alcohol de-addiction treatment.

The system analyzes handwriting samples and extracts measurable handwriting features such as:

- Letter formation patterns  
- Writing pressure  
- Word spacing  
- Stroke structures  

These features are analyzed using **Convolutional Neural Networks (CNNs)** and image-processing techniques to detect behavioral traits linked to relapse risk.

The predictions are validated using responses from the **Alcohol Relapse Risk Scale (ARRS)** questionnaire.

---

# Motivation

Traditional relapse monitoring methods often rely on:

- Counselor observations  
- Self-reported patient responses  
- Behavioral interviews  

However, individuals may unintentionally hide or suppress their true emotional state during therapy sessions.

Handwriting provides a behavioral signal that reflects subconscious cognitive and emotional patterns. By analyzing handwriting traits computationally, the system provides a **non-invasive, data-driven approach** for identifying hidden behavioral indicators related to relapse risk.

# Dataset Description

The dataset consists of handwriting samples collected from individuals undergoing alcohol rehabilitation treatment.

Dataset characteristics:

- **Total samples:** 75 handwritten pages  
- Each participant wrote **three paragraphs**
- Pages were scanned and stored as digital images
- Images were processed for feature extraction

Each handwriting sample was analyzed for:

- Pen pressure (light / medium / heavy)
- Word spacing (even / uneven)
- Letter formation patterns

Key letters analyzed by the CNN models include:

```
g, y, d, t, e
```

These letters were selected because their stroke shapes and loops reveal behavioral traits such as self-discipline, emotional control, and sensitivity to criticism.

Participants also completed the **Alcohol Relapse Risk Scale (ARRS)** questionnaire, which was used to validate the handwriting-based predictions.

# System Architecture

The HITT system follows a modular pipeline:

1. Handwriting Sample Upload  
2. OCR Character Detection  
3. Letter Extraction  
4. CNN-based Trait Classification  
5. Pressure Analysis  
6. Word Spacing Analysis  
7. Ensemble Model Integration  
8. Report Generation  

The final output predicts whether the handwriting indicates **recovery patterns or relapse tendencies**.

---

# Methodology

## 1 Image Preprocessing

Handwriting images undergo preprocessing steps:

- Convert image to grayscale
- Resize to fixed resolution
- Normalize pixel values
- Apply thresholding and edge detection

This prepares the handwriting images for reliable feature extraction.

---

## 2 Character Extraction

OCR techniques are used to detect characters and extract specific target letters:

```
g, y, d, t, e
```

Each detected letter is cropped and saved for further analysis.

---

## 3 CNN-Based Trait Detection

Specialized CNN models analyze handwriting traits including:

- Loop structures
- Stem height
- Stroke orientation
- Character shape variations

Each model detects behavioral indicators linked to relapse or recovery.

---

## 4 Pressure Analysis

Pen pressure is estimated using grayscale intensity variations.

Pressure is categorized into:

- Heavy Pressure
- Medium Pressure
- Light Pressure

Pressure patterns help estimate emotional stress levels.

---

## 5 Word Spacing Analysis

Word spacing is calculated using bounding box detection.

Spacing classification:

- **Even spacing → emotional stability**
- **Uneven spacing → potential relapse indicators**

---

## 6 Ensemble Model Integration

The system combines predictions from:

- CNN handwriting trait models
- Pressure analysis
- Word spacing analysis

These components form an **ensemble model** that produces the final relapse prediction.

---

## 7 Report Generation

The system generates a structured **Excel report** containing:

- Character frequency counts
- Extracted handwriting traits
- Predicted relapse or recovery indicators

This report can assist clinicians, researchers, and counselors in evaluating behavioral trends.

# Results

The handwriting analysis system demonstrated strong predictive performance.

Examples of CNN model accuracy:

| Trait Model | Accuracy (%) |
|-------------|-------------|
| d-Loop | 94.55 |
| t-Loop | 89.95 |
| Mirrored t | 87.58 |
| y-Loop | 92.70 |
| g-Loop | 80.29 |
| e-shape | 74.00 |

The **ensemble model achieved approximately 90.6% accuracy** for relapse prediction.

Additionally, handwriting predictions showed **87% agreement with ARRS questionnaire responses**, indicating strong clinical relevance.
